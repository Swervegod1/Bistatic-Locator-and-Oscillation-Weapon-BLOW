1. Procure All Components

Use the updated Bill of Materials (bom_optimized.csv) to order parts. Key substitutions from the original design:

· MEMS microphones: Vesper VM3011 (piezoelectric, survives high‑SPL TX bursts).
· TX drivers: EPC2032 GaN FETs + LMG1210 gate drivers (replace DRV8870).
· Environmental sensor: Bosch BME280 (adds temperature/humidity compensation).
· ELINT LNA: Mini‑Circuits PSA4‑5043+ (one per antenna element).
· Peltier cooler: 40×40 mm TEC module for the TX array.
· Power sequencer: Texas Instruments UCD90120A.

2. Fabricate the PCBs

· Open the KiCad project (ultrasonic_tile.kicad_pcb) in KiCad 7.
· Run Design Rules Check (DRC) to verify no errors.
· Export Gerber files and NC Drill files using File → Fabrication Outputs → Gerbers and Drill Files.
· Order the 25×25 mm 4‑layer boards from JLCPCB, PCBWay, or OSH Park.
· Order the dipole PCBs for the ELINT array (custom FR4, 100 MHz tuned).

3. Assemble the Hardware

Ultrasonic array (×16 tiles):

· Solder surface‑mount components in this order: passives (resistors, capacitors), op‑amps, T/R switch, ADC, GaN FET, gate driver, transducer, connectors.
· Use a reflow oven or hot plate if possible; the ADS127L11 has fine pitch.
· Connect the tiles to the FPGA via the 40‑pin ribbon cable bus described in system_integration.md.

ELINT array (×2 stations):

· Mount the four crossed‑dipole antennas on the aluminum cross‑boom.
· Connect each dipole through a balun (Mini‑Circuits T1‑1T‑KK81+) and LNA (PSA4‑5043+) to the KerberosSDR.
· Power the LNAs via bias‑tee.

Central processing station:

· Assemble the Jetson Orin (or x86 PC), connect the USRP B210 (GNSS) and KerberosSDR (ELINT) via USB 3.0/Ethernet.
· Connect the FPGA board via USB‑UART and Ethernet.

4. Program the FPGA

· Create a Vivado project targeting Artix‑7 XC7A35T (Arty A7 board).
· Add these Verilog files:
  · tdoa_core_optimized.v (TDOA pipeline with DSP/BRAM optimisations)
  · tx_beamformer_optimized.v (MMCM‑based phase control)
  · adc_reader.v, pulse_detector.v, capture_buffer_dualport.v, tdoa_correlator_optimized.v, uart_tx.v (all from the design package)
· Synthesise, implement, and generate the bitstream.
· Load the bitstream onto the Arty A7 using the Vivado Hardware Manager.

5. Set Up the Host Software

Install Ubuntu 22.04 with PREEMPT_RT kernel:

```bash
sudo apt update
sudo apt install linux-image-rt-amd64 linux-headers-rt-amd64
```

Run setup_rt_kernel.sh to isolate CPUs, set IRQ affinity, and add real‑time group limits. Reboot.

Install ROS2 Humble and dependencies:

```bash
sudo apt install ros-humble-ros-base python3-colcon-common-extensions
pip3 install numpy filterpy pyserial smbus2 bme280
```

Build the gnss‑sdr shadow detector:

· Clone gnss‑sdr, apply gnss_shadow_detector_patch.diff.
· Build with cmake -DENABLE_UHD=ON .. && make -j$(nproc).

Compile the Pothos topology (optional):

· Install Pothos framework and custom blocks for MUSIC/UART.

Install Eclipse Iceoryx for zero‑copy ROS2 transport:

```bash
sudo apt install ros-humble-rmw-iceoryx-cpp
```

Set RMW_IMPLEMENTATION=rmw_iceoryx_cpp in your environment.

6. Calibrate the System

GNSS station survey:

· Place each GNSS antenna at its permanent location.
· Use RTKLIB in Static PPP mode to log 24 hours of L1 data.
· Compute sub‑centimeter antenna coordinates and store them in the TDOA solver configuration.

Ultrasonic array calibration:

· Mount the fixed reference pinger at a precisely surveyed point (e.g., 2 m directly above array centre).
· Run calibration.py on the host. It will collect TDOA offsets and send them to the FPGA.
· The offsets are stored in FPGA BRAM for real‑time correction.

ELINT phase calibration:

· Place a signal generator with a small monopole at a known far‑field location.
· Inject a 100 MHz tone and record the phase differences across the four KerberosSDR channels.
· Store the phase offset table in the MUSIC processing script.

BME280 environmental compensation:

· Verify the sensor is connected to the host’s I²C bus (pins 3/5 on Raspberry Pi or Jetson).
· The fusion_ukf.py node reads temperature and humidity every second and adjusts the speed of sound.

7. Start the Detection and Tracking Services

Launch the system in this order:

1. GNSS shadow detector: gnss-sdr --config_file=shadow_station1.conf (on each station’s computer).
2. ELINT tracker: python3 cmos_clock_df.py (on each KerberosSDR host).
3. Ultrasonic TDOA listener: The FPGA automatically starts capturing upon ping detection; the host runs kalman_tracker.py (or fusion_ukf.py) to read UART lags.
4. Fusion node: ros2 run drone_defence fusion_ukf.py
5. Health monitor: python3 health_monitor_daemon.py

Check the ROS2 topic /drone_pose using ros2 topic echo /drone_pose to confirm 3D tracking is live.

8. Test with Simulated Targets

GNSS shadow simulation:

· Follow sim_target_gen_guide.md. Use HackRF One + gps‑sdr‑sim with a programmable attenuator to mimic a drone shadow. Verify the shadow detector triggers.

Ultrasonic target simulation:

· Use a function generator connected to a small 40 kHz transducer to emit pings at known positions. Confirm the TDOA solver reports the correct 3D location.

ELINT test:

· Excite a drone camera module on the bench (without video transmission). The DF array should lock onto its 72 MHz harmonic.

9. Deploy and Tune

Covariance intersection hand‑off:

· The fusion_ukf.py node automatically performs covariance intersection when a new sensor track appears. Adjust the lambda parameter (0.5 by default) to control the blend between GNSS and acoustic covariance ellipsoids.

TX beamformer tuning:

· Place a calibrated ultrasonic microphone at a known distance.
· Command a low‑power test beam (10% duty) and measure the focal spot size. Adjust phase calibration offsets until the spot is <5 cm at 10 m.

IMU resonance sweep (optional):

· To confirm the kill frequency for a specific drone, mount its flight controller on a vibration table, sweep 26–28 kHz with a high‑speed camera, and log the IMU I²C bus using a logic analyser (Sigrok/PulseView) until you see saturation.

10. Activate the Kill Mechanism

1. Wait for a stable track on the GUI (pose covariance ellipse is small).
2. Issue the kill command: ros2 service call /trigger_kill std_srvs/srv/Trigger
3. The host sends the target coordinates + K header over serial to the FPGA.
4. FPGA switches all tiles to TX mode, computes phase delays, and fires a 1‑second 27 kHz burst at full power (GaN FETs enabled).
5. The drone’s MEMS gyro saturates; the drone crashes within 1 second.
6. FPGA returns to RX mode, and the array confirms target loss on the tracker.
7. The Peltier cooler activates for 30 seconds to cool the TX array.

11. Maintenance

· Run the health monitor daemon continuously. It checks KerberosSDR phase coherence every 30 seconds and restarts the sync service if drift exceeds 5°.
· Re‑calibrate the ultrasonic array weekly (or after large temperature swings) by re‑running calibration.py.
· Keep the GNSS station coordinates updated; re‑survey after any physical disturbance.
· Check GaN FET temperatures; the TEC should keep them below 60°C.
