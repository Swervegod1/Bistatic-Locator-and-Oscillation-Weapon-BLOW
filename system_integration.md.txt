# Ultrasonic Drone Defence System — Integration Guide


## 1. Power Architecture
- 24 V DC bus (from AC adapter or battery) feeds all 16 tiles and the FPGA board.
- Each tile converts 24 V → 5 V (LDO LM7805) and 5 V → 3.3 V (AMS1117‑3.3).
- FPGA board (Arty A7) powered via its own barrel jack or from 5 V rail.


## 2. Wiring
- All 16 tiles connect to the FPGA via a single 40‑pin ribbon cable bus:
  - 1 GND
  - 2 +3.3V (shared)
  - 3 +5V (shared)
  - 4 CTRL_TR (daisy‑chained or separate FPGA pins)
  - 5 TX_PWM (per‑tile)
  - 6‑9: SPI (shared SCLK, MOSI, MISO, per‑tile CS)
- Per‑tile CS uses FPGA GPIO; 16 CS pins needed.


## 3. Calibration
- Place a 40 kHz piezoelectric beeper at 1 m directly above the array centre.
- Record TDOA offsets for each channel and store in FPGA block RAM (or host config file).


## 4. Operation Sequence
1. Power on; FPGA loads bitstream.
2. Host PC starts `kalman_tracker.py`.
3. Array listens for pings; when a drone is detected, tracking begins.
4. To neutralise: operator presses a key; host sends target coords + `K` to FPGA.
5. FPGA switches all tiles to TX mode, computes phase delays, emits 27 kHz burst.
6. Drone gyro saturates; drone crashes.
7. FPGA returns to RX mode.


## 5. Safety
- TX burst limited to 1 second by FPGA timer.
- Power budget: 24V × 0.5A = 12W per tile TX (192W total). Ensure cooling.
- Wear hearing protection; 140 dB SPL at 40 kHz is inaudible but still high energy.
